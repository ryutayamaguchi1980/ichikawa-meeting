# 月次営業会議シート（市川店）

営業メンバーが会議前に実績・振り返りを入力し、A3横1枚で印刷して持ち寄るためのWebアプリ。

## 使い方

1. 担当営業（中村・西野・山口）を選ぶ
2. ターゲット居宅・実績・振り返りなどを入力（選択すると自動保存）
3. 「A3プレビューを見る」→「印刷」
4. プリンター設定で **A3・横向き** を選択して印刷

## シートの構成

| セクション | 内容 |
|---|---|
| 基本情報 | 会議日・対象月・担当営業 |
| ① ターゲット居宅（3件） | 居宅名・担当ケアマネ・目標訪問数・実際の訪問数・達成率（自動計算） |
| ② 実績 | レンタル・用品・住宅改修・手すり・現調（先月実績を自動表示） |
| ③ その他の目標と結果 | 自由に行を追加できる表 |
| ④ 今月の振り返り | やったこと / 良かったこと / うまくいかなかったこと / 気づき・学び |
| ⑤ 全体共有 | 困りごと相談 / 成功事例共有 / 改善案・提案 |
| ⑥ 来月の行動 | 重点活動 / チャレンジすること / 協力してほしいこと |
| ⑦ 会議メモ | 当日記入欄（部長・SVコメント、決定事項） |

達成率は 100%以上=緑 / 70%以上=黄 / それ未満=赤 で色分けされます。

## 便利な機能

- **一覧**：保存したシートを月ごとに表示。開く・削除ができます
- **翌月分**：ターゲット居宅・担当ケアマネ・目標を引き継ぎ、実績と振り返りを空にした翌月のシートを作成します
- **先月実績の自動表示**：同じ担当営業で前月のシートが保存されていれば、実績欄に先月の数字が自動で並びます

## データの保存について

入力内容は**使っている端末のブラウザ内**（IndexedDB）に保存されます。サーバーには送信されないため、他のメンバーの入力内容は画面に出てきません。会議では各自が印刷して持ち寄る運用を想定しています。

## 技術スタック

- React 18 + Vite
- Tailwind CSS v3
- Dexie.js（IndexedDB）
- lucide-react（アイコン）
- 印刷：`window.print()` + `@media print`（A3横）

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm run build   # 本番ビルド
```
